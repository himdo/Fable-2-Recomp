# Security policy

## Reporting a vulnerability

Please report security problems privately using **Report a vulnerability** on
this repository's Security tab. If that option isn't available, open an issue
asking for a private contact, and leave the details out of it.

Include what is affected, how to reproduce it and the release or commit you
tested. Please don't attach game files or disc images.

## What is covered

- The game executable and launcher from the latest release
- The disc extractor in `tools/x360extract`
- The build scripts and how they fetch dependencies

Gameplay bugs, crashes with no security impact and problems in the upstream
ReXGlue SDK that this project doesn't patch are better reported as normal
issues or upstream.
