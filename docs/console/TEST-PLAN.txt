Fable 2 developer commands - console-v7
=======================================

What it is: one command, "f2", in the ReXGlue SDK's own console. Press ~ in
game, type  f2 <command>,  press Enter. Nothing runs until the first f2
command, so a normal launch is unchanged. The work lives on the "console"
branch; build it with build.cmd -release fable_2 (no installer).

Why v6 should help: v5 could only call what we already knew. v6 adds ~110
commands grouped by area (health, hero, money, items, world, camera, ui,
render, entities, debugfns, places) plus host tools to find and change memory
(scan, findf, findstr, peekf/pokef) and to automate (every, repeat, history,
autoexec, cvar). Calls whose argument shape is a guess try (entity, args) and
then (args); the reply ends in [shape 1] or [shape 2], which tells us the real
shape.

Why v7 should help: v5/v6 guessed many argument lists, and several were wrong
(giveall passed no hero, warp level passed one argument instead of three,
Camera.* missed the camera object, spawnat/combatants/killall/skill/weapon had
the wrong arguments). v7 reads the game's own compiled scripts
(tools/lua_callshapes.py -> docs/console/LUA-CALL-SHAPES.md) and calls each
function the way the game does. It also adds travel, flee, control,
teleportent, addskill, ability/title/trackedstat name lists, and ~80 quick
shortcuts with their real parameters.

UNTESTED in game. Checked in a mock harness with fake engine tables, and the
argument lists match the game's compiled scripts.

v7 first (these were wrong before):
     f2 giveall potions | f2 giveall weapons 4 | f2 weapon ObjectInventory_L_LongSword_Iron
     f2 spawn CreatureFaunaChicken 3 | f2 combatants CreatureHobbe 2 | f2 killall
     f2 skill 0.5 | f2 ability list | f2 ability fireball 3 | f2 title ChickenChaser
     f2 fov | f2 fov 90 | f2 zoom | f2 sfx SE_GOLD_PAYMENT | f2 ui counter 3 10 | f2 ui counter off
     f2 quick list | f2 travel list | f2 travel bowerstone (loads a region; save first)

Steps
1. Start the game, load a save (use a throwaway save: some commands change it).
2. Press ~ and type:  f2 help
   Expect group lines ("health: hp heal ...", "ui: ui msg", ...). If nothing
   shows in ~, look in logs\ for [console] lines and tell me: that means
   cprint does not reach the ~ console.
3. Host side (answers always show in ~):
     f2 hosthelp | f2 status | f2 cvar
     f2 cvars ui            -> console\cvars.txt
     f2 history | f2 again
     f2 repeat 3 echo hi    -> three "[echo] hi" lines
     f2 every 2s echo tick  (wait 6 s)  f2 every stop all
4. Hero and stats, one at a time:
     f2 hp | f2 hp 1 | f2 heal | f2 invuln on | f2 invuln off
     f2 mana on | f2 sprint on | f2 speed 2 | f2 speed off
     f2 money | f2 money set 5000 | f2 stats
     f2 renown 100 | f2 title | f2 outfit list | f2 outfit pirate
5. World, camera, UI:
     f2 clock | f2 dayspeed 20 | f2 dayspeed 1 | f2 stoptime on | f2 stoptime off
     f2 day | f2 season winter | f2 season summer | f2 ground | f2 snap
     f2 fov | f2 fov 90 | f2 zoom | f2 campos | f2 shake 3
     f2 ui state | f2 ui msg hello | f2 ui hud off | f2 ui hud on
     f2 ui icons off | f2 ui icons on | f2 ui fadeout 1 | f2 ui fadein 1
6. Rendering:
     f2 engine            (lists Debug.EngineConfig into the log)
     f2 shadows off | f2 shadows on | f2 vis lod | f2 vis off | f2 mist off
7. Entities (target someone first, or use the dog):
     f2 inspect | f2 inspect dog | f2 dog bark | f2 dog here
     f2 tp dog | f2 bring dog | f2 near 15 | f2 combat target fight off
8. Debug helpers:
     f2 dbg list | f2 dbg list weapon | f2 quick list | f2 probe Stats.GetMorality
9. Memory scan (gold as the example):
     f2 money                      note the number, say 1234
     f2 scan start 1234
     buy or sell something, f2 money again, say 1180
     f2 scan next 1180             repeat until a few are left
     f2 scan list                  then: f2 peek <addr> 16
10. Places that survive a restart:
     f2 warp save here; place export
     copy the "place set ..." line into <game root>\console\autoexec.txt
     restart, type f2 status, then f2 warp here
11. Close the game, start it again, do NOT type f2: nothing console-related
    should run, and F5 must still work.

Send back:
- What ~ printed for each step (a screenshot is fine), or the [console] lines
  from logs\ if Lua replies did not show in ~.
- Every line ending in [shape 1] or [shape 2] (these confirm argument shapes).
- Every "failed:" line with its error text.
- Which commands did nothing visible, and anything that crashed (with the
  last command typed).
