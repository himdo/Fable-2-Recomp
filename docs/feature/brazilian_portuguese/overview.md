# Brazilian Portuguese language pack

**Status:** open PR #242 · **Commits:** bf3eb48, b53cbb8, c5d3c15 (#242) · **Last checked against:** 7863041

The Windows launcher can add Brazilian Portuguese to the game's language menu. The community pack translates menus, subtitles and Pub Games text. Dialogue uses the original English voices. The game remembers the language in your player profile.

## Install and select the language

1. Extract your GOTY disc and close the game. The tested combination is GOTY USA/Europe and Beta 0.9.1 of the [community translation by @diocarvalho](https://github.com/diocarvalho/Fable2-PTBR-Project/releases).
2. In the launcher menu bar, open **Merge Locales → Merge Brazilian Portuguese** and select the downloaded ZIP.
3. Start the game, open the language menu and choose **Portuguese (Brazil)**. Enable subtitles to see translated dialogue.

You can switch languages in the game at any time. To uninstall the pack, close the game and choose **Merge Locales → Remove Brazilian Portuguese**. This restores the original language files. Keep the launcher's backup with the extracted game until removal finishes. Remove the pack before extracting the disc again into the same folder.
