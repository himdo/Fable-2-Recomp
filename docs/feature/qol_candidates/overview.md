# Quality-of-life candidates: overview

**Status:** no commit yet (research only) · **Commits:** none · **Last checked against:** c2a9d12

## What this is

A wish list built from the [player complaints](../player_complaints/overview.md), split into things the recomp could reasonably add and things that are out of reach. For each item it notes what the game or the recomp already has to build on. Nothing on it has been agreed with the maintainer yet. The full details are in [technical.md](technical.md).

## Out of reach

Anything that needs new story, new voice lines or new art: a new ending or final boss, more quests, more weapons and spells, sailing. Split-screen co-op with two cameras and bringing back online co-op are also too big. Adding content from Fable III, or sharing game files, isn't allowed.

The old website bonus items aren't on either list because they're already back: the recomp unlocks them from your own copy of the game, on by default. The Collectors Edition items are unlocked the same way, but that still needs checking in game.

## What players can use today

- **Slow menus:** **High Tick Rate** in the launcher makes menus react faster. It's marked unstable and makes some minigames easier.
- **Keys:** the launcher's **Keybinds** section moves any key or mouse button.
- **Achievements:** press **F7** in game.
- **Website and Collectors Edition items:** on by default (launcher).
- **Backups:** copy the saves folder next to the game.

## What players need to do

Nothing. If you'd like one of these, say so on the project's issue tracker.
